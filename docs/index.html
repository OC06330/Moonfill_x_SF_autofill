Moonfill x SF_autofill

Two one-click jobs on Salesforce: run a Moonpull integration scan with the result posted to the record's Chatter, and fill in and save the record's Technical Checklist.

Download for Edge & Chrome Release notes

Version 3.0.1 · Microsoft Edge or Google Chrome on your work computer

What it does

🌙 Moonpull scan

The Submit Moonpull form button on the record submits the scan for you and waits for the result. It then posts the result to Chatter and fills in the scan fields.

  • No typing the MID or region
  • Run several scans at once
  • Progress in the toolbar popup

✅ Technical Checklist

The Checklist Autofill panel, bottom right of the record, fills in the team's agreed answers and saves the record.

  • Pixel Sent and Successful Tracking Test dates set for you
  • Platform templates, picked automatically from the client's site
  • Fill only to check first, Clear checklist to empty it
  • Your own values in Settings

🔎 IR and 🚀 New Implementation

Buttons on the record open the Internal Review or New Implementation pages for the advertiser in Awin, as one tab group.

Before you start

Browser

Microsoft Edge or Google Chrome, signed in to Salesforce and Microsoft 365 in the same browser.

Scan results folder

Scans need access to the shared Moonpull batch results folder. Ask Rodier or Thomas on Teams. The checklist needs no extra access.

Replacing an old version?

Let any running scans finish, then remove the old Moonfill and the separate SalesforceAutofill extension first.

Install

  1. Download the zip and unzip it somewhere permanent, for example in Documents. Keep the Moonfill folder: the extension runs from it.
  2. Open edge://extensions in the address bar.
  3. Turn on Developer mode (bottom left).
  4. Click Load unpacked and choose the Moonfill folder, the one containing manifest.json.
  5. Click the puzzle icon in the toolbar and pin 🌙 Moonfill.

  2. Open chrome://extensions in the address bar.
  3. Turn on Developer mode (top right).

Optional: to have checklist templates picked automatically, open Moonfill's Settings (link on the checklist panel) and click Allow platform detection.

Update

  1. Download the new zip from the latest release.
  2. Replace the files in your Moonfill folder with the new ones.
  3. On the extensions page, click the reload icon on the Moonfill card.

Good habits

Scans

  • Always start from the program's record.
  • Let the form finish filling itself in (about 25 seconds).
  • Keep the browser open until the scan says Complete.

Checklist

  • Open the record's Details tab first.
  • Not sure? Use Fill only, check, then Save.
  • If it stops, the panel says why. Nothing is saved.

Privacy

Moonfill works on the page in front of you, using your own Salesforce and Microsoft 365 logins. It counts each use (checklist fills, Moonpull scans, New Implementation and IR) by the record's Assigned TC, to measure adoption. No client information is recorded.
